# Telegram Books v0.1.0 — первый тестовый релиз

Нативное локальное приложение на Rust + GPUI для скачивания книг из Telegram-каналов
личного аккаунта. WebView и отдельного сервера нет.

## Скачать

- **macOS Apple Silicon:** ZIP для `aarch64-apple-darwin`.
- **Windows 10/11 x64:** NSIS-установщик `setup.exe` для текущего пользователя.
- Рядом с каждым пакетом — SHA-256 для проверки целостности.

Rust, Cargo и инструменты упаковки для запуска не нужны.
Это **Pre-release**, не стабильная production-сборка.

## Подписи и первый запуск

**Релиз без доверенных подписей издателя.**

- macOS `.app` имеет только локальную ad-hoc подпись, без Developer ID
  и нотариализации. Gatekeeper может заблокировать первый запуск скачанного
  приложения. Если macOS предлагает разрешение, оно находится в
  «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».
  Приложение не снимает quarantine и не отключает защиту ОС.
- Windows-установщик и `.exe` не подписаны Authenticode. SmartScreen / антивирус
  могут предупреждать о неизвестном издателе; корпоративная политика может
  полностью запрещать запуск.
- Контрольная сумма проверяет целостность, но не заменяет подпись издателя.

## Что работает

- Вход в Telegram по телефону, коду и 2FA; зашифрованная локальная сессия.
- Каналы, чтение первых 100 сообщений при выборе, поиск и фильтры вложений.
- PDF, EPUB, FB2, MOBI, DJVU, ZIP; последовательная очередь без параллельных файлов.
- Прогресс, скорость и ETA, отмена и докачка после сбоя / перезапуска.
- SQLite-история и библиотека, папка по умолчанию и явное повторное скачивание.
- Сохранённые источники, мониторинг новых книг с рекомендациями без автоскачивания.
- Системные уведомления с кнопкой «Тест».

## Установка

**macOS:** распакуйте ZIP и откройте `.app`. Вне `/Applications` и `~/Applications`
приложение предложит установку. «Только для меня» использует `~/Applications`.
Копирование требует подтверждения; исходная и существующая установленная копии
не удаляются и не заменяются автоматически. Перед запуском новой версии закройте старую.

**Windows:** запустите `setup.exe`. По умолчанию установка выполняется для текущего
пользователя, без запроса прав администратора. Установщик не настроен на удаление
книг, истории или Telegram-сессии при деинсталляции.

Credentials вводятся локально в приложении. Не присылайте API hash, коды, пароль
или файлы сессии в GitHub Issues.

## Ограничения и что проверить на Windows

- Успешная сборка / тесты в CI не заменяют ручную проверку установленного приложения
  на реальных Windows 10/11. Этот релиз предназначен в том числе для такой проверки.
- Проверьте установку, иконку, DPI / масштабирование, вход, выбор папки, скачивание,
  уведомления, перезапуск и докачку. Затем проверьте сохранность пользовательских
  данных после удаления приложения.
- Докачка требует ручного продолжения очереди. Частичные файлы старых версий
  без контрольной точки использовать нельзя.
- Нет автоматического обновления, параллельных загрузок, смены тем и встроенного ридера.
- Заявленный минимум macOS — 12.0; сборка на новой macOS сама по себе не подтверждает
  ручную приёмку на 12.0.
- После смены ad-hoc сборки macOS может снова запросить доступ к Keychain.
- Защищённый контент Telegram не скачивается.

Лицензионные тексты приложения и сторонних зависимостей включены в пакет
в папку `licenses` (на macOS — `Contents/Resources/licenses`).
